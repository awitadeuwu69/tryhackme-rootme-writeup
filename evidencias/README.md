## Reglas para publicar evidencias

- Ocultar flags completas, contraseñas, tokens, cookies de sesión y claves.
- No subir archivos de shell funcionales, payloads o archivos de acceso remoto como evidencia pública.
- Usar nombres descriptivos, por ejemplo `nmap-resumen.png` o `panel-validacion.png`.
- Indicar en el README principal qué hallazgo demuestra cada evidencia.
- No presentar capturas de guías ajenas como evidencia de ejecución propia.
